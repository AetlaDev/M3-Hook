**中文** | [English](#english)

## 安装

[点击安装脚本（始终为最新版本）](https://aetladev.github.io/M3-Hook/m3-hook.user.js)

首次安装需已启用油猴（Tampermonkey / Violentmonkey）扩展。脚本更新由 `@downloadURL` / `@updateURL` 自动跟随部署产物，无需重新安装。

## English

### Installation

[Install the userscript (always the latest version)](https://aetladev.github.io/M3-Hook/m3-hook.user.js)

A userscript manager (Tampermonkey / Violentmonkey) must be installed first. Updates are picked up automatically through `@downloadURL` / `@updateURL`, so no reinstall is needed.
